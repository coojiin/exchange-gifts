# 交換禮物 · 動畫與 UI 第一版

## 使用

解壓縮後直接用瀏覽器開啟 `index.html`。不需要安裝套件、建置或連接外部服務。
將此資料夾中的 `index.html`、`style.css`、`script.js` 替換原專案對應檔案即可更新畫面；`logic_test.js` 是開發驗證用，不會載入網頁。

## 這一版

- 深松綠、酒紅、香檳金視覺；桌面雙欄與手機單欄。
- 名單只對新項目播放進場；刪除淡出後其他項目平順移位。
- 參加者卡片選取回饋、完整畫面進出場動畫。
- 金色轉盤、外圈燈光、跨格指針撥動、停止亮起。
- 約 5.6 秒的加速／巡航／減速，停住後進入禮盒拆封揭曉。
- 新紀錄加入動畫、已完成人數與進度條、遊戲結束畫面。
- 音效開關、鍵盤焦點、結果視窗焦點限制、減少動態效果偏好支援。
- 名字以純文字顯示，單引號與 HTML 字元不會被當成程式執行。

## 保留的規則

`getValidTargets()` 與原版本完全相同：不抽自己的禮物、不抽已被取走的禮物，兩人剩餘時保留原有防死結檢查。
每次轉動只選取一次結果，轉盤只呈現該結果；只有一個有效選項時跳過轉盤，直接開盒。按確認後才將禮物標記為已抽走並新增紀錄。
維持目前頁面內的遊戲狀態；重新整理會重新開始。

## 驗證

```sh
node --check script.js
node logic_test.js
```

已通過：

- 2～5 人所有有效選人順序與結果：13,326 個狀態、5,510 次完整遊戲。
- 重複轉動／確認／選人保護。
- 轉盤停止位置與實際結果對齊。
- 揭曉不寫入紀錄，確認只提交一次。
- 單一候選跳過轉盤及減少動態效果的揭曉流程。

測試直接載入正式程式，邏輯窮舉使用實際候選方法；互動狀態測試使用簡化的畫面物件，不等同真實瀏覽器驗證。
本次環境無法啟動瀏覽器，也沒有可連線的瀏覽器，因此視覺、實際動畫流暢度、音效及手機觸控尚待實機確認。

## 瀏覽器驗收

1. 新增 3 位嘉賓，試著新增重複名字、移除後重新新增名字。
2. 點選參加者，轉盤轉動時連點按鈕，確認只有一份結果。
3. 檢查指針所在名字與開盒名字相同，按確認後只增加一筆紀錄。
4. 完成所有抽獎；另開新頁以 2 人測試跳過轉盤直接開盒。
5. 在手機或窄視窗確認按鈕、長名字與結果視窗可見；開啟系統「減少動態效果」再試一次。
6. 切換音效開關，確認後續跨格及揭曉音效遵循設定。
